# flintchart-compile example

Compiles an embedded flint `ChartAssemblyInput` (a 4-point monthly revenue
bar chart) via `ntshim/flintchart.Compile`, then displays the compiled
size, warning count, and the pretty-printed spec JSON on the page.

This proves the compile bridge alone — rendering the resulting spec with
ntcharts in a browser TUI is [go-booba](https://github.com/NimbleMarkets/go-booba)'s
domain, not this example's.

```sh
task serve
```

Then open <http://localhost:8000/>.

## Browser verification

After `task serve`, the page should show
`compiled ok — 60x16 cells, 0 warning(s)` in `#status` and the
pretty-printed spec JSON in `#envelope`.

Verified on 2026-09-28, before the ntshim migration, in headless Chrome using
the actual Go/WASM program and assets generated by `booba-shim-assets`: compilation succeeded with
60x16 cells, zero warnings, and the expected bar-chart spec. This checks the
compile bridge; the example does not render the resulting chart.

Verified again on 2026-10-19 in Safari after the ntshim migration, using the
rebuilt Go/WASM example and assets installed by `go tool ntshim-assets`:
60x16 cells, zero warnings, and the expected bar-chart spec.

`node smoke.mjs` checks the vendored JavaScript bundle directly, without
exercising the Go/WASM bridge.
