# ntshim/duckdb — native Arrow example

The page defaults to DuckDB-Wasm. Open `?engine=haybarn` or use the page's
engine links to run the same Go/WASM Arrow tour with Haybarn-Wasm.

```sh
task serve
```

then open <http://localhost:8000/>. Five rows of `n` and `n^2` from a
DuckDB Arrow IPC reader.
