# ntshim/duckdb — database/sql example

The page defaults to DuckDB-Wasm. Open `?engine=haybarn` or use the page's
engine links to run the same Go/WASM SQL tour with Haybarn-Wasm.

```sh
task serve
```

then open <http://localhost:8000/>. The page should show ping ok and two
rows from a parameterized SELECT.
